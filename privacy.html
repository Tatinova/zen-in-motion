Privacy Policy

Zen in Motion · Last updated: September 29, 2026

Who we are

Zen in Motion (ZIM) is operated by Tati Novaes. This policy explains how data is handled by the private automation tool used to run the ZIM business.

What this tool is

ZIM uses a private automation tool called "n8n connection". It is used only by its owner to connect her own Google account (Gmail, Google Sheets, Google Drive, Google Calendar) to her own automation workflows. It is not a public product and is not offered to other users.

Google user data we access

With the owner's explicit permission, the tool may read and write data in the owner's own Google account, such as emails, spreadsheets, files and calendar events, only to run the automations she has set up.

How we use and store data

Data is processed only to perform these automations. It runs on a private server controlled by the owner. We do not sell data, share it with third parties, use it for advertising, or use it to train AI models.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as needed for the automations. Access can be revoked at any time at myaccount.google.com/permissions. To request deletion of any data, contact us below.
